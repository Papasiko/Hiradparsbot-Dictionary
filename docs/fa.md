# مستندات فارسی Hiradparsbot Dictionary

Hiradparsbot Dictionary یک صفحه‌ی سبک و واکنش‌گرا برای معرفی Hiradparsbot و جست‌وجوی واژگان انگلیسی و فارسی است. ابزار دیکشنری به‌صورت پنجره‌ای شناور در پایین سمت راست صفحه باز می‌شود و کاربر را از صفحه خارج نمی‌کند.

## امکانات
- طراحی تک‌صفحه‌ای با ترکیب رنگ آبی تیره و فیروزه‌ای.
- سازگار با نمایشگر موبایل و دسکتاپ.
- دکمه شناور دیکشنری در گوشه پایین سمت راست.
- باز و بسته شدن پنجره دیکشنری بدون جابه‌جایی به صفحه دیگر.
- تشخیص خودکار زبان ورودی فارسی یا انگلیسی و امکان تغییر دستی جهت جست‌وجو.
- جست‌وجوی انگلیسی به فارسی و نمایش معنی‌های موجود، نقش دستوری، تعریف و مثال.
- جست‌وجوی فارسی به انگلیسی و نمایش گزینه‌های انگلیسی قابل انتخاب.
- امکان کپی نتیجه و شنیدن تلفظ با قابلیت‌های مرورگر در صورت پشتیبانی.

## راه‌اندازی روی GitHub Pages
1. فایل `index.html` باید در ریشه مخزن قرار داشته باشد.
2. در مخزن GitHub وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. نشانی GitHub Pages پس از انتشار در همان صفحه نمایش داده می‌شود.

## منبع واژگان و نحوه کار
این صفحه برای جست‌وجوی واژه‌ها از API عمومی پروژه متن‌باز [Openjam](https://github.com/amirj4m/openjam) استفاده می‌کند:

`https://openjam.amirj4m.com/v1`

بانک واژگان در این مخزن کپی نشده است؛ صفحه هنگام جست‌وجو به API عمومی Openjam درخواست می‌فرستد. در نتیجه، جست‌وجو به فعال بودن سرویس و محدودیت‌های اعلام‌شده از طرف پروژه Openjam وابسته است. مستندات API برای هر IP محدودیت ۶۰ درخواست در دقیقه را ذکر می‌کند.

این ابزار دیکشنری واژه‌محور است و جایگزین مترجم جمله‌های آزاد نیست. برای واژه‌هایی که در بانک داده ثبت نشده‌اند ممکن است نتیجه‌ای نمایش داده نشود. کیفیت و کامل بودن معنی‌ها نیز به داده‌های منبع وابسته است.

## وابستگی‌ها و هزینه
- برای جست‌وجوی واژه‌ها نیازی به Google Cloud، فعال‌سازی Billing، کلید API یا Cloudflare Worker اختصاصی این پروژه نیست.
- دسترسی به اینترنت برای ارتباط با API عمومی Openjam لازم است.
- سرویس API متعلق به پروژه Openjam است؛ پایداری و محدودیت‌های آن تحت کنترل این مخزن نیست.
